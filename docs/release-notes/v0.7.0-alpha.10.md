# Fantasy Earth 0.7.0-alpha.10

## Naming migration

- Canonical public name: `Fantasy Earth / 魔幻地球`
- Canonical mod id and resource namespace: `fantasy_earth`
- Canonical repository and artifact prefix: `fantasy-earth`
- Canonical Java package: `com.xxsx.fantasyearth`
- Legacy `earth_online_magic:*` block, item, entity, block-entity, menu and feature ids resolve through NeoForge registry aliases.
- Legacy `earth_online_arcana.*` player data migrates to `earth_arcana.*` on first access.

## Gameplay, worldgen & visual updates (`6af7583`–`f62237a`)

- **Creature motion & settlement variety (`6af7583`)**: adds 4 custom particle types (`aether_mote`, `crystal_shard`, `rune_spark`, `ward_rune`) across spells, stations, seats, anchors and creatures; gives all creature models custom idle, gait and attack animations; lowers settlement density to roughly 1 per 500–900 chunks, adds dwarven delving and elven grove worldgen layouts with randomized rotation/palette, and makes the ritual core a reusable catalyst.
- **Local aether-field spell charging (`101e362`)**: spell graphs declare `local_aether` and consume chunk AEU on cast (rejecting casts when local field density is insufficient and disturbing the chunk); adds emissive aura layers to custom creatures and enriches settlements with paths, fences, scattered vegetation and a ruined variant.
- **6-creature skeletal & texture overhaul (`84ac93e`–`f62237a`)**: fixes `RuneWolfModel` body-part armor attachment, adds Blockbench 5.0 `.bbmodel` sources (`art/blockbench/entities/*.bbmodel`), and rebuilds all 6 entity models (`AetherFoxModel`, `ManaWispModel`, `RuneWolfModel`, `CrystalSpiderModel`, `RunicWatcherModel`, `ArcaneSettlerModel`) with articulated angled sub-bones, directional fur/chitin/crystal/rune shading, and refreshed spawn egg textures.
